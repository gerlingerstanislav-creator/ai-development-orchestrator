# AI Development Orchestrator

Веб-платформа для совместной разработки проектов людьми и ИИ-агентами: от постановки задачи и анализа до кода, тестов и pull request.

**Статус:** подготовка к MVP. Технологический стек обсуждается, не утверждён.

## Принципы
- Серверный веб-сервис для нескольких участников.
- Основной интерфейс — проекты, канбан/список, карточка задачи, документация, чат.
- ИИ-роли (аналитик, разработчик, тестировщик) независимы от поставщика модели.
- Оркестратор управляет этапами, лимитами, очередями, зависимостями и восстановлением работы.
- Работа с GitHub pull request внутри веб-интерфейса.
- Изолированные рабочие окружения агентов; production не изменяется автоматически в первой версии.
