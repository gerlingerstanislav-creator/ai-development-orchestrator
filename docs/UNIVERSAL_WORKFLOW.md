# Универсальный workflow и профили сложности

Основной процесс: **бэклог → анализ → разработка → тестирование → очередь слияния → выкладка → документация → готово**. «Вопросы к ПО» — блокировка до ответа, а не способ обойти качество. При ошибке QA работа возвращается разработчику в существующий PR.

## Профили

- **Быстрый** — краткое уточнение и адресная QA-проверка для локальных задач.
- **Стандартный** — полный цикл, установлен по умолчанию.
- **Расширенный** — глубокий анализ рисков, проверка интеграций, регрессии и восстановления.

Профиль определяет глубину анализа и проверки, а также ожидаемое участие ролей. **Не отменяет серверные ограничения**: проверенный анализ, независимое архитектурное ревью, CI, QA по актуальному SHA, безопасный merge, режим выкладки и документацию. Это НЕ отдельный механизм оркестрации и не разрешение игнорировать проверки.

Профиль проекта применяется к вновь созданным задачам, а не задним числом к выполняющимся. Задача хранит собственный снимок профиля. Его можно изменить только в бэклоге или анализе, до запуска анализа и до PR. Изменение профиля после анализа отправляет задачу на повторное уточнение.

## Ответственность

**PM** координирует исключения и принимает результат; **аналитик BA/SA** формирует требования; **разработчик** реализует и исправляет; **QA** независимо проверяет; **архитектор** консультирует и ревьюит; **DevOps** отвечает за релиз; **документатор** обновляет документацию. Детальная матрица участия каждого профиля доступна на странице Workflow.

Процессы по-прежнему исполняются в Temporal, а события и артефакты находятся в Центре процессов.

## API

- GET /api/projects/:id/workflow/profiles — каталог профилей и значение проекта.
- PATCH /api/projects/:id/workflow/profile — изменить профиль новых задач (администратор).
- POST /api/projects/:id/tasks с необязательным workflow_profile — задать профиль создаваемой задачи.
- PATCH /api/projects/:id/tasks/:taskId с workflow_profile — изменить профиль пока анализ не выполняется.

Существующие маршруты workflow и их семантика сохраняются.
